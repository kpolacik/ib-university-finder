# Backlog

Work that has been decided on but not started, kept here so it is not lost
between batches. Started 2026-10-26 (Leon's decision Q16).

Every item is named by its ID in the issue registry, `plans/audit-issues.md`
(D = data, P = points, R = cards, T = sign-off, S = search, L = loading,
A = accessibility, X = security, M = maintenance, F = features, Q = decisions).
These files never invent their own numbering. The registry is the
authoritative list: its State column says which file here holds an item.

The registry itself is still local to this checkout (everything under `plans/`
except `plans/scan/` and this folder is excluded from git), so a successor may
see an ID here without the registry next to it. The two audits it was merged
from are tracked in `plans/scan/`.
